# 第 1 步：把用药打卡规则改正确

状态：已完成并通过本步检查。完成版本标记：`mvp-v2-step-01`。

## 做完后能体验什么

在现有页面里，长辈可以按新规则打卡、延后、补记和更正；子女看到同一结果。新首页和完整日历在第 2 步呈现。

## 本步功能

- [x] 早餐、午餐、晚餐、睡前四自然时段；按时段结束判断未按时打卡，不再使用提醒后 60 分钟规则。
- [x] 已服用／未服用／本次无需服用三种选择；不强制实际服药时间和数量，规则接口允许保留主动自述。
- [x] 每个任务仅延后一次，可选 5 或 30 分钟；保护期内不显示逾期红点，刷新、撤销不恢复次数。
- [x] 本人可补记逾期和历史任务；5 秒撤销，后续可更正，保留前后版本。
- [x] 新计划仅生成适用的当前和未来任务；编辑／停用保留已开始任务及原药名、剂量、安排快照。
- [x] 当天有任务，且全部已服用／本次无需服用才点星；未服用、未记录、无任务不点星。
- [x] 当天补记可恢复星星；次日首次补记不补旧星；历史更正留痕且不覆写原日结算依据。
- [x] 跨午夜延后保留原任务；固定基准日加受控日期偏移。
- [x] 兼容旧存档和旧状态，不推断餐后或实际服药事实；恢复初始数据可用。
- [x] 账号与家庭共享保留；声明、补记、更正、延后均限制长辈本人。

现有表单在本步只支持业务规则，完整外观、滚轮及首页排布归第 2 步；可见通知归第 3 步。
