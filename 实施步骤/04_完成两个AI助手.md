# 第 4 步：完成两个 AI 助手

状态：未开始。前提：第 3 步完成。完成版本标记：`mvp-v2-step-04`（完成后创建）。

## 做完后能体验什么

从首页进入助手查询、记录或添加；从加药页面进入助手时直接开始整理药品信息。输入不同内容，最终记录也会不同。

## 本步功能

- [ ] 两个账号首页都有助手按钮；点击进入文字模式，长按进入同一聊天页的模拟语音模式，主动问候、给建议，松手不重复打开。
- [ ] 加药页面提供手动输入和 AI语音输入两种模式；后者进入就询问药品信息，不重复询问意图。
- [ ] 两个入口共用消息、输入草稿、配置卡和最终核对；手动／聊天来回切换不覆盖已有修改。
- [ ] 支持实际文字、明确标记的示例语音和点选混合输入；示例先预览后发送，取消不保存，不请求麦克风或上传音频。
- [ ] 已知信息回显，只追问缺项或冲突；支持约定范围内的否定、半片、改口和餐时修改，无法理解时澄清或转手动。
- [ ] 查询已有的今天／晚间用药、几点提醒、计划用量；多目标先选择，无任务如实回答，不给医疗建议。
- [ ] 创建药品计划：完整采集、点选四时段／提醒／餐时／周期，统一核对，确认后才保存。
- [ ] 本人记录当次是否服用、延后 5／30 分钟、补记和进入本人更正流程；不强制提供实际时间或剂量，不猜任务，不批量代选。
- [ ] 新记录成功后，若仍有符合条件的逾期任务，逐项提示；“没有按时服用”先澄清究竟是否吃过。
- [ ] 记录血压、血脂和身体指标，可留用户转述备注，核对测量时间、数值及单位后保存，联动 BMI。
- [ ] 子女可查询、协助添加和发起合格提醒；所有输入方式都不能代打、更正或延后。
- [ ] 消息、未发送文字和草稿在回桌面、看通知、转表单、切意图后可恢复；账号／档案之间隔离，返回原对象可继续。
- [ ] 保存结果更新首页、历史、子女看板、星星和 BMI，刷新保留；未确认草稿不冒充已保存。

不接真实语音识别和模型 API；有限文字规则无法处理的输入保留并转手动。无对应计划的临时服药记录不擅自新增模型。未提交聊天草稿跨刷新恢复不是本次必做，按浏览器能力提示可能丢失。

## 怎么检查

1. 两角色分别点击和长按进入，问候、对象及可用操作正确；查询今天和晚间用药，再追问几点、多少。
2. 输入“示例药，每次一片，早晚吃”，确认时段，再改成半片；切手动修改餐时，回聊天后核对保存，结果确实随输入变化。
3. 测试缺项、否定、未知表达、取消示例；助手不瞎填，原输入不丢失。
4. 本人记录、延后、补记并处理遗漏追问；子女通过文字、示例和任务卡尝试代打均被拒绝。
5. 录入三种身体数据；草稿中途回桌面、点通知、换对象再返回，内容恢复且不串档；确认结果刷新后仍可查询。
